# 刘玉娇 · 个人主页

计算机专业大一学生的个人主页，通识课程结课作业。

**在线访问：** https://liu-iris1671.github.io

## 项目说明

一个**单文件、零外部依赖**的个人主页，直接在手机上或电脑浏览器里打开即可，无需任何服务器环境。

- 全部样式（CSS）内嵌，不引用任何 CDN、字体库或图片资源
- 头像、蝴蝶、星星、图标、分割线全部为内联 SVG 或纯 CSS 绘制
- 头像照片以 Base64 内嵌，因此整个网站只有 `index.html` 一个文件

## 页面结构

| 模块 | 内容 |
|---|---|
| 首屏 | 头像、姓名、专业、个人 slogan、向下指引箭头 |
| 关于我 | 学习态度、学习方式、本学期的小目标 |
| 技能 | 目前主攻 C 语言的真实学习进度 |
| 项目 | 项目区暂为空，附项目路线图 |
| 页脚 | 版权与课程作业说明 |

## 技术要点

- HTML5 语义化标签
- CSS3：自定义变量、Grid / Flex 布局、关键帧动画、渐变与遮罩、媒体查询响应式
- 原生 JavaScript：开场幕布时间线、IntersectionObserver 滚动进场、导航高亮、滚动进度条

## 本地预览

直接用浏览器打开 `index.html` 即可。

## 部署

推送到本仓库的 `main` 分支后，GitHub Pages 会自动发布更新。
